Features

Everything you need to automate your desktop

Six core capability pillars — from offline speech to screen-aware OCR — all running locally with zero cloud dependency.

🎙️

Offline Speech-to-Text Pipeline

Karn AI listens continuously using a multi-engine offline STT stack. The Vosk model handles real-time partial transcripts for responsive feedback, while Whisper provides high-accuracy final transcriptions. A Voice Activity Detection (VAD) layer ensures the microphone only activates during actual speech — cutting false triggers and preserving CPU. The result is a hands-free command loop with sub-second recognition that works entirely without internet.

PowerShell Confirm Mode

Shell commands are queued behind a nonce-based confirmation gate. An optional passphrase adds a second layer for destructive operations. Execution only proceeds after explicit human approval — no silent automation of risky commands.

Nonce gate Passphrase Queue
⚡

Dual-Engine Intelligence — Deterministic + LLM

Common phrases like open notepad or create folder never touch the LLM — they hit a fast deterministic parser (core/commands.py) for zero-latency response. When a request falls outside predefined patterns, brain/llm.py forwards it to your local Ollama model, normalizes the JSON response, and routes the resulting action. This hybrid means speed for daily tasks and flexibility for open-ended queries — with all inference running on your own hardware.

Deterministic fast path Ollama fallback JSON normalization llama2 / any model

Web Control Panel

A lightweight Flask server (web_panel.py) exposes browser-based control: monitor assistant status, send text commands, toggle voice mode, and call API endpoints — reachable at http://127.0.0.1:5000.

Architecture

How it all fits together

Five modules, one cohesive runtime. Each layer has a single clear responsibility.

01

core/commands.py — Fast Parser

Pattern-matches incoming text against a library of deterministic phrases. Handles the 80% of common commands instantly without touching the LLM, keeping latency near zero for everyday tasks.

02

brain/llm.py — LLM Fallback

For unrecognized requests, this module calls your local Ollama instance, normalizes the JSON action response, validates it, and returns a structured intent that the action layer can execute.

03

core/actions.py — Task Executor

Receives structured action objects and carries out desktop operations: subprocess calls, PyAutoGUI interactions, OCR queries, and browser navigation — all returning structured result objects.

04

core/assistant_service.py — Orchestrator

Central runtime that stitches together the voice loop, memory persistence, command routing between the fast parser and LLM fallback, and retry logic with configurable delays.

05

web_panel.py — Control Panel

Flask app that exposes REST endpoints for the browser UI — status checks, manual command injection, voice mode toggling, and real-time log streaming.

Quick Start

Running in three steps

Python 3.10+, a running Ollama daemon, and microphone access. That's all you need.

📦 Install & Launch
# 1. Install Python dependencies
pip install -r requirements.txt

# 2. Download offline STT models
python setup_offline_stt.py

# 3. (Optional) Pull your LLM model
ollama pull llama2

# 4. Start the assistant
python main.py

# Or start only the web panel
python web_panel.py

Security

Designed for safety by default

Every execution path that touches your system has a guard. Nothing runs without you knowing about it.

🔐 PowerShell Confirm Gate

Shell commands are placed in a queue and only executed after you provide a nonce token. An optional passphrase adds a second factor for destructive operations. The gate is always on by default.

📁 Filesystem Sandboxing

All file and folder operations are validated against the project base directory before execution. Commands attempting to escape the sandbox are rejected before they reach the OS.

🖱️ OS Accessibility Permissions

OCR and automation actions that interact with other applications require explicit OS-level accessibility permissions. Karn will not silently acquire these — your system's permission dialog always mediates access.

Troubleshooting

Common issues & fixes

STT not starting
Re-run python setup_offline_stt.py and verify that Vosk and Whisper model paths are correct. Check that your microphone is accessible by the terminal process and that the VAD library is installed.
No OCR features
Install Tesseract OCR and ensure the tesseract binary is available in your system PATH. On Windows, add the install directory (e.g., C:\Program Files\Tesseract-OCR) to PATH manually.
LLM issues
Confirm the Ollama daemon is running (ollama serve) and that the model specified in KARN_MODEL has been pulled (ollama list). Check available RAM — large models like llama2 need at least 8 GB.
Voice output broken
Verify the Piper .onnx model file path set in KARN_VOICE_MODEL_PATH is correct and the file exists. Check audio device permissions and ensure your default output device is active. Run a quick TTS test with python -c "from core.tts import speak; speak('test')".
